# 人格与关系探索小程序

原生微信小程序首版，包含 5 套短测评、确定性本地评分、长结果页、关系延伸阅读、双人结果码、SBTI 和塔罗式意象卡。

## 本地运行

1. 安装并打开微信开发者工具。
2. 导入本目录，AppID 可先使用测试号。
3. 项目根目录已配置 `miniprogramRoot: miniprogram/`。
4. `npm test` 运行评分单元测试，`npm run check` 检查页面和数据文件。

浏览器里的 `npm run preview` 只是方便看设计和快速答题；真正的小程序入口是微信开发者工具导入后的 `miniprogram/`。

继续开发前请先阅读 [`HANDOFF.md`](HANDOFF.md)，其中记录了当前主流程、五套结果结构、兼容约束和微信开发者工具待验证项。

## 变成可以发布的微信小程序

1. 在微信公众平台注册小程序，取得正式 AppID。
2. 把 `project.config.json` 中的 `touristappid` 换成正式 AppID。
3. 在微信开发者工具选择“导入项目”，目录选本项目根目录；工具会读取 `miniprogramRoot: miniprogram/`。
4. 用开发者工具的模拟器和“真机调试”完成：首页、全部答题、返回、结果保存、删除结果、双人结果码和塔罗式意象卡回归。
5. 在小程序后台补齐名称、图标、服务类目、用户隐私保护指引和版本说明。
6. 在开发者工具点击“上传”，再到小程序后台提交审核；审核通过后由管理员发布。

当前 `appid` 仍是测试值，所以现在可以开发和体验，不能直接提交正式审核。

## 内容审阅

- `content-review-v2.md`：100 道测试题、全部结果分支、双人规则和 18 张塔罗式意象卡；16 型人格固定 36 题，完成后直接出结果。
- `npm run export:content`：从当前代码重新生成内容审阅稿。

## 产品边界

- 测试用于自我探索，不是心理诊断、咨询或择偶判决。
- 题目、评分与结果均为本地确定性规则；AI 问答未启用。
- SBTI 是原创娱乐测试，不冒充心理量表。
- 塔罗入口仅提供象征性自我反思，不预测未来、运势或感情结局；正式提审前仍需复核微信最新内容规则。
- 结果和作答默认仅保存在本机。
- 双人关系地图只读取双方主动分享的结构化结果码，不上传聊天内容。
