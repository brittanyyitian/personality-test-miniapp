# 社交模式结果页趣味手账设计

## 目标

在不改动 17 种社交人格的数据、题库映射、头图尺寸和结果流程的前提下，把头图以下的统一结果母版从连续白色卡片升级为“人格观察手账”。视觉更活泼，同时保证长文可读、按钮清晰和小程序包体稳定。

## 视觉语言

- 清透的象牙纸张作为底色，使用奶油杏、浅湖蓝、淡米黄和冷白灰作为主要卡片色，不使用紫色，也避免大面积粉色与黄绿。
- 共鸣句使用干净的白色摘录卡；四个特征使用低饱和、轻微错落的贴纸卡片。
- 社交倾向使用手绘刻度与荧光笔进度条。
- 六段分析统一使用白色卡片与浅灰蓝虚线描边，以编号圆章和重点词高亮维持层级；右上角轮换使用小星点、双圆点和短纸胶带，控制装饰密度，正文保持水平排版。
- 朋友标签使用聊天气泡贴纸；AI 观察使用暖粉便签；拼图进度使用雾蓝卡片承接。
- 装饰通过 CSS/WXSS 的伪元素、边框、阴影和旋转完成，不增加新图片素材。
- 底部操作区与正文便签分开，不添加票根、印章或英文装饰；分享按钮为深蓝黑，其他动作使用雾蓝和淡粉。

### 平衡版收口

在视觉反馈中把“彩色手账”和“纯白极简”收敛到中间状态：保留明亮纸张分区、极轻的旋转与阴影，但每个区块最多出现一个装饰焦点。页面以象牙白、奶油杏和浅湖蓝为主体，橙红色只用于编号、进度和重点文字；边框随卡片色变化，避免统一褐灰造成脏感。底部操作区继续取消容器，只保留深色主按钮、浅湖蓝次按钮和奶油杏关系入口。

## 实现边界

- 只对 `result-kind-social` 生效，其他人格结果页保持现状。
- 小程序和网页预览使用相同的 class 语义与视觉参数。
- 不改变结果数据结构、题库签名映射、分享数据或交互逻辑。
- 头图现有尺寸与 PING 横图专属校正保持不变。
- 分享短海报根据头图宽高比自适应：横版素材使用紧凑画布与较短头图区，竖版素材保留标准海报比例，避免 `contain` 产生大段上下留白。

## 验证

- 运行现有单元测试、静态检查和 diff 检查。
- 选择 PING、SPARK、SLEEP 验证横图、活跃型竖图和低电量竖图。
- 检查正文可读性、横向溢出、贴纸错落、按钮层级和 17 种类型共用模板的稳定性。
